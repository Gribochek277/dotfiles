feat(pi): pi-sudo — sudo from the bash tool via fingerprint/rofi askpass
pi spawns bash detached without a tty, so `sudo` cannot prompt and fails with
"a password is required". sudo falls back to the askpass helper when no
terminal is available, so the extension writes a themed rofi askpass script to
$XDG_RUNTIME_DIR/pi-sudo/ (0700, tmpfs) and exports SUDO_ASKPASS through
process.env — the bash tool reads the environment live via getShellEnv(), so
the model's command is never rewritten and no shadow `sudo` lands in PATH.

PAM runs first: the fingerprint authenticates with no window at all
(pam_fprintd is in /etc/pam.d/sudo) and rofi only appears when the sensor does
not answer. Nothing reads, caches or writes a password — the credential stays
inside PAM/fprintd; each command authenticates again (without a tty sudo binds
timestamp tickets to the parent pid), one touch per command.

A tool_call hook on bash commands with `sudo` in command position posts a
desktop + TUI hint, since the sensor prompt is otherwise invisible.

Replaces the password-prompting pi-sudo.ts / sudo-askpass.ts drafts.
